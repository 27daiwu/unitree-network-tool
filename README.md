## 🚀 使用教程

### 第一步：连接机器人

使用网线连接 Windows 电脑与 Unitree G1 对应的有线网络接口。

确认机器人已经正常开机，相关网络接口处于可用状态。

### 第二步：配置 Windows 电脑 IP

**重要：使用本工具前，请先将电脑的有线网卡配置到 `192.168.123.x` 网段。**

可以参考以下网络参数：

| 配置项目 | 建议参数 |
|---|---|
| IP 地址 | `192.168.123.222` |
| 子网掩码 | `255.255.255.0` |
| 默认网关 | 按实际网络配置，直连场景通常可留空 |
| DNS | 按需配置 |

`192.168.123.222` 仅为示例，请确保该地址未被机器人或其他设备占用。

**Windows 设置步骤：**

1. 打开 Windows 网络设置。
2. 进入高级网络设置。
3. 找到连接机器人的以太网适配器。
4. 打开 IPv4 属性。
5. 选择手动配置 IP 地址。
6. 输入上述网络参数并保存。

注意：不要直接使用机器人已经占用的 IP 地址。

### 第三步：启动软件

双击运行：

`Unitree-Network-Tool-v1.0.0.exe`

根据软件界面提示，填写对应机器人网络连接参数，并执行需要的配置操作。

请确保输入的机器人 IP、SSH 用户名及密码与实际设备一致。

### 第四步：检查配置

操作完成后，根据软件提示确认配置结果。

必要时，可以使用 Windows PowerShell 测试机器人网络是否可达：

```powershell
ping 192.168.123.164
```

以上地址仅为部分 G1 环境中的参考地址，实际应以机器人当前网络配置为准。

Ping 成功不代表 SSH 服务或所有网络功能均正常。

## ⚠️ 使用注意事项

1. **网络要求**：操作前请确认电脑与机器人处于可通信的网络环境。
2. **SSH 密码**：当前版本的 SSH 密码输入框采用明文显示，操作时注意周围环境，避免密码泄露。
3. **设备兼容性**：当前主要面向 Unitree G1，其他机型尚未完成适配验证。
4. **网络风险**：错误的配置可能导致机器人暂时无法联网或远程访问。
5. **操作建议**：修改配置前，建议记录原始网络参数，以便必要时恢复。
6. **安全建议**：仅在可信网络环境中使用，不要向陌生人员提供机器人 SSH 凭据。
