# Unitree Network Tool

一个面向宇树机器人用户的第三方 Windows 配网小工具。使用 Python 开发，**完全免费、绿色免安装**，下载 EXE 后即可运行。

> **声明：**本工具为第三方独立开发项目，不属于宇树机器人官方产品，也不代表宇树官方提供支持。

## 下载

请在本仓库的 **Releases** 页面下载最新正式版本：

1. 打开仓库右侧的 **Releases**，进入标记为 **Latest** 的正式版本。
2. 下载对应的 `unitree-Network-Tool-vX.Y.Z.exe` 文件（例如首发版 `unitree-Network-Tool-v1.0.0.exe`）。
3. 双击 EXE 运行。无需另外安装 Python，也无需安装向导或在线激活。

**请优先从本仓库的 Releases 页面下载，不建议使用第三方转载的安装文件。** 每个版本的更新说明、文件名以及可用的 SHA-256 校验值均以对应 Release 页面为准。

## 支持范围

- 首发目标机型：**Unitree G1**。
- 后续计划：逐步适配其他型号；新增支持的机型会在相应版本说明中列出。
- 实际适用的固件版本与网络环境，请以各版本的测试说明为准。

## 使用说明

1. 在 Windows 电脑上运行本工具。
2. 按照工具界面提示连接机器人并填写必要的网络或 SSH 连接信息。
3. 确认目标机器人及网络参数无误后，再执行配网操作。

**安全提示：**此版本的 SSH 密码输入框采用明文显示，使用时请注意周围人员、截图和屏幕录制。请勿将 SSH 密码、私钥或其他敏感连接信息上传到 Issues 或公开讨论区。

## 更新方法

本软件**不会自动联网检查或下载更新**，不包含联网激活功能。需要更新时：

1. 关闭正在运行的旧版程序。
2. 前往本仓库 Releases 页面下载最新正式版 EXE。
3. 用新文件替换旧版 EXE，再次运行即可。

请勿删除个人配置或数据文件。后续版本若有配置兼容性变化，会在 Release 更新说明中单独说明。
